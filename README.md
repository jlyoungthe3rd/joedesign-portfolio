# Joe Design Portfolio

A game design portfolio site built with Next.js, highlighting featured project case studies and professional background.

**Live:** https://joedesigns.games

## Key Routes
- `/` - Featured project landing page
- `/projects/project-1` - Department of Malicious Vagueness case study
- `/about` - About
- `/resume` - Resume
- `/projects` - Project index

## Local Run
```bash
npm run dev
```
Open http://localhost:3000

**Stack:** Next.js 15 + React 19 + TypeScript 5 + Tailwind CSS 4 + Framer Motion
